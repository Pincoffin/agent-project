# Local AI Agent System

This is a local-first AI agent built on Ollama.

## Features

- Tool execution
- Memory storage
- Critic feedback loop
- Autonomous task iteration

## Run

python main.py

## Model

Default: qwen-7b via Ollama

## Goal

Build a reliable autonomous agent that:
- Takes a task
- Plans actions
- Executes tools
- Evaluates results
- Iterates
